# Реестр кодов блоков

Коды **уникальны на весь проект**. Благодаря этому требование цитируется коротко — `ЗАК-Ф-01` — в issue, комментарии к коду или обсуждении, и не путается ни с чем.

**Правило:** заводишь новый блок — сначала добавь код сюда, потом используй. Занятый код не переиспользуется под другой смысл даже после удаления блока.

## Структура кода требования

```
ЗАК - Ф - 01
 │    │    └── порядковый номер внутри блока
 │    └─────── слой: О (общее) / Б (бэкенд) / Ф (фронтенд)
 └──────────── код функционального блока
```

**Слой** означает, к чему относится требование:

- **О** — продуктовое правило, не зависящее от реализации. Действует независимо от того, кто его исполняет.
- **Б** — обязанность серверной части.
- **Ф** — обязанность клиентской части.

Код не отражает вложенность: он остаётся плоским, даже если блок лежит глубоко. Иерархия нужна для навигации, а ссылаться удобнее коротко.

## Функциональные блоки

Блоки тоже вкладываются на любую глубину: крупный блок с большим числом требований делится на подблоки, у каждого свой код.

### 1. ОБЩ — Общее

| Код | Блок | О чём |
|---|---|---|
| `АВТ` | Авторизация и сессии | Вход, регистрация, внешний поставщик, способы входа, роли |
| `АДП` | Адаптив | Правило двух раскладок, брейкпоинты, типографика |
| `ФАЙ` | Файлы | Приём, хранение и раздача изображений |
| `ШАП` | Шапка и навигация | Логотип, меню, кнопка поддержки |

### 2. АДМ — Админка

| Код | Блок | О чём |
|---|---|---|
| — | *не определены* | Разграничение доступа и навигация между разделами управления |

### 2.3 АНВ — Админка: новости

| Код | Блок | О чём |
|---|---|---|
| `ВЕД` | Ведение новостей | Создание, изменение, удаление |
| `ИЗО` | Изображения новости | Источники, порядок, текстовое описание |

### 2.4 АТГ — Админка: теги

| Код | Блок | О чём |
|---|---|---|
| `ТЕМ` | Ведение тем | Создание, изменение, удаление, цвета |

### 2.5 АЗК — Админка: закреплённые новости

| Код | Блок | О чём |
|---|---|---|
| `РЕД` | Редактор раскладки | Родительский блок: сборка витрины |
| `РЕД` › `РАБ` | └ Рабочая область | Размер экрана, честность холста, предпросмотр |
| `РЕД` › `РАС` | └ Расстановка | Закрепление, перетаскивание, неразмещённые |
| `ФОК` | Точка фокуса | Выбор участка изображения, остающегося в кадре |

### 5. НОВ — Новости

| Код | Блок | О чём |
|---|---|---|
| `ЛЕН` | Лента новостей | Список, сортировка, подгрузка по прокрутке |
| `ЗАК` | Закреплённые новости | Витрина: показ подборки, расставленной администратором |
| `ФИЛ` | Фильтры и поиск | Периоды, темы, признаки взаимодействия |
| `КАР` | Детальная карточка | Чтение новости целиком |
| `РЕА` | Реакции | Лайки и просмотры |

## Свободные разделы

Для заготовок (`АРС`, `АПЛ`, `ГЛВ`, `ПРФ`, `ТУР`, `ВИД`, `ОСТ`) функциональные блоки не определены — заводятся при наполнении соответствующей спеки, с обязательной записью сюда.
