# Реестр кодов блоков

Коды **уникальны на весь проект**. Благодаря этому требование цитируется коротко — `ЗАК-Ф-01` — в issue, комментарии к коду или обсуждении, и не путается ни с чем.

**Правило:** заводишь новый блок — сначала добавь код сюда, потом используй. Занятый код не переиспользуется под другой смысл даже после удаления блока.

## Структура кода требования

```
ЗАК - Ф - 01
 │    │    └── порядковый номер внутри блока
 │    └─────── слой: О (общее) / Б (бэкенд) / Ф (фронтенд)
 └──────────── код функционального блока
```

**Слой** означает, к чему относится требование:

- **О** — продуктовое правило, не зависящее от реализации. Действует независимо от того, кто его исполняет.
- **Б** — обязанность серверной части.
- **Ф** — обязанность клиентской части.

## Крупные блоки (страницы)

Каждый крупный блок — отдельный документ спеки в `specs/`.

| Код | Страница | Спека | Состояние |
|---|---|---|---|
| `ОБЩ` | Общее — сквозное для всего сайта | `specs/005-common/` | заполнена |
| `ГЛВ` | Главная | `specs/006-main/` | заготовка |
| `НОВ` | Новости | `specs/001-news/` | заполнена |
| `ЛКБ` | Личный кабинет | `specs/007-account/` | заготовка |
| `АДМ` | Админка — оболочка, доступ, навигация | `specs/008-admin-shell/` | заготовка |
| `АРС` | Админка: расписание | `specs/009-admin-schedule/` | заготовка |
| `АПЛ` | Админка: пользователи | `specs/010-admin-users/` | заготовка |
| `АНВ` | Админка: новости | `specs/002-admin-news/` | заполнена |
| `АТГ` | Админка: теги новостей | `specs/003-admin-news-tags/` | заполнена |
| `АЗК` | Админка: закреплённые новости | `specs/004-admin-pinned/` | заполнена |

«Страницы нет» — в приложении объявлен роут, но компонента страницы не существует.

## Функциональные блоки

### ОБЩ — Общее

| Код | Блок | О чём |
|---|---|---|
| `АВТ` | Авторизация и сессии | Вход, регистрация, Google, методы входа, роли |
| `АДП` | Адаптив | Правило двух раскладок, брейкпоинты, типографика |
| `ФАЙ` | Файлы | Приём, хранение и раздача изображений |
| `ШАП` | Шапка и навигация | Логотип, меню, кнопка поддержки |

### НОВ — Новости

| Код | Блок | О чём |
|---|---|---|
| `ЛЕН` | Лента новостей | Список, сортировка, подгрузка по прокрутке |
| `ЗАК` | Закреплённые новости | Витрина: показ подборки, расставленной администратором |
| `ФИЛ` | Фильтры и поиск | Периоды, темы, признаки взаимодействия |
| `КАР` | Детальная карточка | Чтение новости целиком |
| `РЕА` | Реакции | Лайки и просмотры |

### АНВ — Админка: новости

| Код | Блок | О чём |
|---|---|---|
| `ВЕД` | Ведение новостей | Создание, изменение, удаление |
| `ИЗО` | Изображения новости | Источники, порядок, текстовое описание |

### АТГ — Админка: теги новостей

| Код | Блок | О чём |
|---|---|---|
| `ТЕМ` | Ведение тем | Создание, изменение, удаление, цвета |

### АЗК — Админка: закреплённые новости

| Код | Блок | О чём |
|---|---|---|
| `РЕД` | Редактор раскладки | Расстановка, размеры, оформление, предпросмотр |
| `ФОК` | Точка фокуса | Выбор участка картинки, остающегося в кадре |

## Зарезервировано

Коды, занятые под будущие блоки страниц-заготовок, чтобы не были заняты повторно: определяются при наполнении соответствующей спеки.
